Install a Local Web Server & Run a Page

A local web server lets your laptop serve HTML files at http://localhost exactly like a real website.

Option A - XAMPP (Apache)

  1. Download XAMPP from apachefriends.org and install it (default folder C:\xampp).
  2. Open the XAMPP Control Panel and click Start next to Apache.
  3. Put your site in C:\xampp\htdocs\vit-site\.
  4. Open http://localhost/vit-site/ in the browser.

Configuration: C:\xampp\apache\conf\httpd.conf - Listen 80, DocumentRoot "C:/xampp/htdocs". If port 80 is busy, change to Listen 8080.

Option B - VS Code Live Server

  1. Install Visual Studio Code, then the Live Server extension.
  2. Open the project folder in VS Code.
  3. Right-click index.html → Open with Live Server.
  4. The site opens at http://127.0.0.1:5500 and refreshes on save.

Option C - Python (no install)

cd vit-site
python -m http.server 8080

Then browse to http://localhost:8080. Press Ctrl+C to stop.

Working & verification

  • Browser sends an HTTP request to localhost.
  • The server maps the URL to a file in the document root.
  • It returns the file with status 200 OK.
  • Unknown paths return 404 Not Found.
