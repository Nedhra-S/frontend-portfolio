# Front End Design - Assignment Portfolio (Nedhra S, 24MIC0107)

Open `index.html` in a browser (or serve the folder with a local web server - Question 1).

- Menu bar -> one entry per question (Q1 to Q43).
- Each question has an Output tab (live page) and tabs for its HTML / CSS / JS source.
- `q/`      the actual question pages (standalone: html, css, js)
- `assets/` site shell, images, audio/video and the local Bootstrap files
- If you edit a file in `q/` and open the site straight from disk, run `python tools/build_sources.py`
  to refresh the code viewer. Through a local web server it always shows the live file.
